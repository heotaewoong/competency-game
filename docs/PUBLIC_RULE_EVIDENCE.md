# 공개 규칙 근거와 구현 경계

기준일: 2026-09-02

이 문서는 공개된 규칙을 구현에 어떻게 반영했는지 기록한다. 현행 기업 초대형 검사의 비공개 문항, 문항 수, 무작위화, 타이밍, 채점식을 공식과 동일하다고 주장하지 않는다.

## 판정 원칙

1. 2024 공개자료는 9개 게임을 모두 4분으로 표시한다.
2. 2023 개발사 영상의 시간 안내는 일부 게임에서 2024 자료와 다르다.
3. 현행 JOBDA 소개 페이지는 게임별 문항 수·시간·채점식을 공개하지 않는다.
4. 따라서 사이트의 `실전형 연습`은 공개된 조작 흐름을 고정한 독립 훈련 프리셋이며 공식 모의검사가 아니다.

## 핵심 구현 결정

| 게임 | 공개 규칙 반영 | 독립 훈련 경계 |
|---|---|---|
| 가위바위보 | 내 패 → 상대 패 → 혼합 | 문항 수·제한시간 |
| 도형 회전 | 문자 → 격자, 45° 회전·상하·좌우 반전 | 15개 세부 훈련군·최소 경로 피드백 |
| 약속 정하기 | 요일 → 위치 → 음식 → 미탑승 버스 | 문항 분포·노출시간 |
| 길 만들기 | 5×5 반사 경로, 경로 성공과 초과 울타리 감점 분리 | 공식 감점식을 흥내 내지 않고 최대득점 여부로 기록 |
| 마법약 | 4재료·14독립 조합·확률 피드백 | 확률맵·문항 수·근거 정렬 지표 |
| 도형 순서 | 2-back → 2·3-back, 5개 묶음 중 1개 | 근거 없는 라운드별 재추첨 대신 세션 내 동일 묶음 유지 |
| 숫자 누르기 | 점등 → 건너뛰기·두 번 누르기 | 문항 수·제한시간 |
| 개수 비교 | 긍정·부정 의미와 글자 크기를 방해자극으로 사용 | 공식 문항을 복제하지 않은 독자 제작 단어쌍 |
| 고양이 술래잡기 | 6×6 위치·빨강 후 파랑·판단+확신도 | 공식 확신도 보정식 대신 위치 정확도·고확신 오답을 분리 표시 |

새로운 공개 자료와 구현이 충돌하면 이 문서에 출처·버전·판정 근거를 먼저 추가한 뒤 코드를 변경한다.
