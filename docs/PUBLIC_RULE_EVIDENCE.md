# 공개 규칙 근거와 구현 경계

기준일: 2026-09-08

이 문서는 공개된 규칙을 구현에 어떻게 반영했는지 기록한다. 현행 기업 초대형 검사의 비공개 문항, 문항 수, 무작위화, 타이밍, 채점식을 공식과 동일하다고 주장하지 않는다.

## 판정 원칙

1. 현행 응시 안내는 전체 검사 약 80분과 큰 검사 범주만 공개하고, 게임별 문항 수·시간·채점식은 공개하지 않는다.
2. 2024 공개자료는 9개 게임을 모두 4분으로 표시하지만, 2023 자료도 길 만들기 레거시 카드 약 3분과 공식 영상 5분처럼 서로 충돌한다.
3. 2026 Upgrade Report는 과제 설명·연습과 실전 응시를 분리하고, 응시 전에 과제 설명을 다시 확인할 수 있는 흐름을 보여준다. 이는 최신 UI 흐름의 근거이며 게임별 비공개 규칙의 근거가 아니다.
4. 따라서 실제 응시 조건은 기업 초대 안내를 우선하고, 사이트의 `실전형 연습`은 공개된 조작 흐름을 고정한 독립 훈련 프리셋으로 표시한다.

## 핵심 구현 결정

| 게임 | 공개 규칙 반영 | 독립 훈련 경계 |
|---|---|---|
| 가위바위보 | 내 패 → 상대 패 → 혼합 | 문항 수·제한시간 |
| 도형 회전 | 문자 → 4×4 격자, 45° 회전·상하·좌우 반전 | 15개 세부 훈련군·최소 경로 피드백·문항당 20회 연습 예산 |
| 약속 정하기 | 요일 → 위치 → 음식 → 미탑승 버스 | 문항 분포·노출시간 |
| 길 만들기 | 5×5 반사 경로, 경로 성공과 초과 울타리 감점 분리 | 공식 감점식을 흉내 내지 않고 최대득점 여부로 기록. T/B·12개 유형은 비공식 개인 공략을 바탕으로 만든 독립 훈련 분류 |
| 마법약 | 4재료의 1·2·3개 조합·확률 피드백 | 가능한 14개 조합 전체 열거·확률맵·문항 수·근거 정렬 지표 |
| 도형 순서 | 2-back → 2·3-back, 5개 묶음 중 1개 | 근거 없는 라운드별 재추첨 대신 세션 내 동일 묶음 유지 |
| 숫자 누르기 | 점등 → 건너뛰기·두 번 누르기 | 문항 수·제한시간 |
| 개수 비교 | 긍정·부정 의미와 글자 크기를 방해자극으로 사용, 1초 제시·3초 생각 | 공식 문항을 복제하지 않은 독자 제작 단어쌍 |
| 고양이 술래잡기 | 6×6 위치·빨강 후 파랑·판단+확신도 | 공식 확신도 보정식 대신 위치 정확도·고확신 오답을 분리 표시 |

## 화면 흐름 결정

- 게임 진입 화면은 `과제 이해 → 방식 선택 → 훈련 시작` 순서로 핵심 목표와 입력 방식을 먼저 보여준다.
- `설명·연습 시작`과 `실전형 연습 시작`을 별도 행동으로 제공한다. 이는 2026 공개 보고서의 분리 원칙을 따르되 JOBDA 화면·브랜드·자산을 복제하지 않은 독립 설계다.
- 세부 난이도 설정은 접어 두고, 공식 공개 근거와 독립 연습값의 경계를 시작 전에 확인할 수 있게 한다.

새로운 공개 자료와 구현이 충돌하면 이 문서에 출처·버전·판정 근거를 먼저 추가한 뒤 코드를 변경한다.
